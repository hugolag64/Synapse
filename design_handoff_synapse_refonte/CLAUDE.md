Synapse = app web personnelle de pilotage des études médicales / prépa EDN, en **NiceGUI + Quasar (Python)**. On refond **uniquement la couche présentation** en un cockpit décisionnel dense inspiré de Linear (structure) + Obsidian (connaissance reliée). ## Règles d'or (non négociables)
1. **Réutiliser Quasar** (`q-layout`, `q-drawer`, `q-list`, `q-tabs`, `q-tab-panels`, `q-dialog`, `q-linear-progress`, `q-chip`) plutôt que réécrire. Ne custom que ce que le README marque « custom ».
2. **Tokens d'abord.** Une seule feuille de surcharge CSS via `ui.add_head_html`, chargée globalement, mappant les variables `--*` sur `:root` et `[data-theme="dark"]` (valeurs exactes = section Design Tokens du README). Aucune couleur/spacing en dur ailleurs.
3. **Grammaire de statut** : une seule dimension par la couleur (rouge/ambre/vert = urgence + santé maîtrise). Progression = forme (○◔◑◕◉●). Type = étiquette mono. Reporté = opacité. Jamais de badge coloré décoratif.
4. **Aucun émoji comme icône.** Glyphes géométriques Unicode + `<kbd>`. (Lucide si un vrai set devient nécessaire.)
5. **Densité** : lignes ≤44px, listes scannables, pas de grande carte vide. Rayons 4/6/8 (plafond 8). Une seule ombre (popover). Transitions ≤180ms sur couleur/bordure/opacité.
6. **Reporter/replanifier** = offset depuis la date d'échéance théorique (jamais depuis aujourd'hui) ; `task_id` et date théorique préservés.
7. **Montrer un diff avant d'écrire** sur les fichiers existants. Ne pas toucher au backend.
8. Un écran par session ; commits atomiques par écran.

## Critères d'acceptation (rappel — détail dans le README)
Action recommandée visible sans scroll · une seule couleur porteuse de sens · aucun émoji-icône · lignes ≤44px · ⌘K + nav clavier + sélection persistante + panneau contextuel fonctionnels · cohérence clair/sombre (AA) · report = offset échéance · responsive complet · transitions ≤180ms.

## Écarts NiceGUI/Quasar à anticiper
Command palette (fuzzy + ⌘K + clavier) = custom. Planning dense = grille CSS custom. Minuteur focus = timer Python/JS. Courbe d'oubli + graphe notions = SVG custom (ECharts en option). Quasar impose ripple/rayons/ombres → feuille de surcharge : désactiver ripple, rayons 4/6/8, retirer ombres sauf popover, forcer la palette de tokens.
