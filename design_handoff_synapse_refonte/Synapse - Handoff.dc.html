  • Titres ≥ 22px : letter-spacing −0.5 %
  • Emphase = poids 600, jamais d'italique

Espacement · rayons · profondeur

  • Base 4px : 4/8/12/16/24/32/48/64
  • Rayons : 4 (contrôles) · 6 (boutons/champs) · 8 (cartes/dialogues) — plafond 8px
  • 1 seule ombre : 0 2px 8px rgba(0,0,0,.04) (popover/dialogue)
  • Motion : 120–180ms ease-out, couleur/bordure uniquement
  • Densité : information/pixel — pas de grandes cartes vides

5 · Règles responsive

  • ≥1200px — 3 colonnes : sidebar + centre + panneau contextuel.
  • 900–1200px — panneau contextuel devient un drawer superposé ; l'en-tête du détail item passe à la ligne.
  • 768–900px — sidebar réduite en icônes par défaut.
  • <768px (mobile) — sidebar → bottom nav ; version simplifiée : résumé + action recommandée + file compacte ; le détail s'ouvre en drawer plein écran ; panneau contextuel empilé.
  • Tables → paires clé/valeur empilées sous 640px ; titres descendent d'un cran par breakpoint.

7 · Critères d'acceptation

  • La page Aujourd'hui répond en <5s à « quoi faire maintenant, pourquoi, quelle ressource » : action recommandée visible sans scroll.
  • Une seule couleur porteuse de sens (rouge/ambre/vert = urgence) ; aucun badge coloré décoratif.
  • Aucun emoji comme icône ; glyphes géométriques + <kbd>.
  • Densité : file de travail entièrement scannable, lignes ≤ 44px de haut, aucune grande carte vide.
  • ⌘K, navigation clavier, sélection persistante, panneau contextuel fonctionnels.
  • Cohérence clair/sombre sur tous les composants (contraste AA sur texte muted).
  • Report = offset depuis la date d'échéance ; date théorique préservée (task_id inchangé).
  • Responsive : 3 colonnes ≥1200px, drawer <1200px, bottom nav <768px.
  • Transitions ≤180ms, couleur/bordure uniquement.
